FILE: 02_RAD_DINO_Feature_Extraction_and_Hyperparameter_Tuning.ipynb
WHAT THE NOTEBOOK DOES
1. Configures the RSNA Stage-2 verifier and discovers RT-DETR candidate proposals and ROI crops.
2. Re-labels proposals using an IoU threshold and loads the corresponding crop images.
3. Extracts 768-dimensional [CLS] embeddings from microsoft/rad-dino using GPU FP16.
4. Caches the embeddings so repeated verifier experiments do not need to run the image encoder again.
5. Creates a patient-stratified train/validation split and checks patient overlap.
6. Runs a grid search over logistic-regression regularization, class weighting, score-fusion weight and threshold.
7. Fits a tuned linear probe and a small MLP, then compares false-positive pruning at several thresholds.
8. Saves diagnostic plots and research artifacts.

RESULTS RECORDED IN THE NOTEBOOK
- 10,094 ROI proposals from 2,018 patients; positive proposal rate about 12.1%.
- All 10,094 crops were loaded; cached feature matrix shape: (10,094, 768), about 31 MB.
- Patient split: 1,210 train patients and 808 validation patients; overlap count 0.
- Validation set: 489 TPs and 3,512 FPs; baseline 4.3465 FP/image.
- Selected grid-search settings: C=0.01, class_weight='balanced', fusion alpha=0.75, threshold=0.30.
- Reported grid-search AUROC: 0.6081; reported FP reduction at selected setting: 62.5%.
- Tuned linear probe AUROC: 0.6081.
- 15-epoch MLP validation AUROC: 0.5878 (epoch 5: 0.6097; epoch 10: 0.5910).
- The separate threshold table reports: threshold 0.35 -> 77.9% FP reduction with 64.8% recall; threshold 0.45 -> 93.3% FP reduction with 34.8% recall; threshold 0.50 -> 97.0% FP reduction with 21.5% recall.
- Final summary table reports Stage 1: 489 TP / 3,512 FP; Stage 2 at tau=0.30: 370 TP / 1,317 FP, precision 21.9%, recall 75.7%, FP/image 1.630, FP reduction 62.5%.

IMPORTANT INTERPRETATION
- The notebook's reported AUROC of 0.6081 is modest; the threshold table's very high FP reduction comes with substantial TP loss at higher thresholds.
- The notebook's 62.5% selected-setting figure and its later threshold table are different operating points/outputs. Keep the definitions and evaluation subset explicit when presenting them.

POSSIBLE UPGRADES
- Do not choose hyperparameters and report final performance on the same validation data without nested validation or a separate untouched test set.
- Keep threshold selection separate from final evaluation; report one final test result at a preselected clinical operating point.
- Check that grid-search scoring uses the intended validation labels and that the fusion alpha/threshold are optimized on validation only.
- Compare against detector confidence alone and a simple tabular baseline using exactly the same split.
- Evaluate calibration, PR-AUC, sensitivity, precision and FP/image with patient-level bootstrap intervals.
- Add patient-grouped cross-validation and repeat seeds.
- Clarify the discrepancy between the 62.5% headline result and the threshold table; include the exact threshold and denominator for every result.
